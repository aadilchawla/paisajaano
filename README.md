# PAISAJAANO

Financial Education Program for Underprivileged Youth in Rajasthan

## About

PAISAJAANO is a comprehensive financial education program designed to empower rural youth in Rajasthan with practical money management skills. Through visual learning materials and community-driven approach, we aim to build a stronger, financially literate future generation.

## Features

- Visual, activity-based learning materials
- Local language instruction
- Practical money management tools
- Community support system
- Government scheme integration
- Interactive teaching materials

## Website

This repository contains the source code for the PAISAJAANO website. The website is built using:

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- Responsive design principles

## Setup

1. Clone the repository:
```bash
git clone https://github.com/yourusername/paisajaano.git
```

2. Navigate to the project directory:
```bash
cd paisajaano
```

3. Open index.html in your browser or use a local server:
```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
